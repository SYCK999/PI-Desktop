## 本次改动说明

在**每条已完成的 Assistant 回复气泡下方**的消息元信息（`message-meta`）中，
新增展示**响应耗时**和**消耗的 token 总数**，方便直观看到每次对话的性能与用量。

### 显示内容

| 展示项 | 说明 |
|--------|------|
| 模型名 | 原有行为，保留 |
| 响应耗时 | 如 `12.3s`（新增） |
| 消耗 token 总数 | 如 `1,234 tokens`（新增） |
| 生成速度 | `≈ N tokens/s`，仅在 provider 未返回 usage 时显示（原有行为） |

### 涉及文件

- `apps/desktop/src/features/chat/transcript/shared.tsx`
  - 修改 `MessageMeta` 组件：新增耗时 chip 与 token chip 的渲染。
  - token 取值优先级：`usage.totalTokens` → `responseOutputTokens`（>0 时）。
  - 耗时取 `responseDurationMs` / 1000，保留 1 位小数。
- `packages/i18n/src/locales/{en,zh-CN,zh-TW,de,es,fr,ko,tr}/index.ts`
  - 新增两个 i18n key：`chat.usageElapsed`（耗时）、`chat.usageTotalTokens`（token 总数）。

### 计时口径说明（重要）

当前显示的「响应耗时」**只统计流式输出阶段**，不包含排队与首 token 生成时间。

时间线（`packages/agent-runtime/src/runtime.ts`）：

```
requestStartedAt = Date.now()   // 请求发出
   │   （排队 + 网络 + 首 token 生成 —— 未计入）
streamStartedAt = Date.now()    // 第一个 token 开始
   │   （流式输出 —— 计入）
endedAt = Date.now()            // 流结束
```

存入 message 的值：

```ts
responseDurationMs = Math.max(0, endedAt - streamStartedAt)
```

代码中另测有 `providerWaitMs = streamStartedAt - requestStartedAt`，
但仅在请求失败时用于错误诊断，**未存储、未展示**。
因此实际体感总时长会偏长于本数值。若要展示完整耗时（含排队），
需改动 `packages/agent-runtime`（跨层，需重新 bundle + 重启），待后续决定。
